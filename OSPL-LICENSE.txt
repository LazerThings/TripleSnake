EXPLANATION OF KEY TERMS:

"Incorporates, uses, or is derived from" means any software that includes 
this Software's code, links to it, calls its functions, or is built upon it 
in any way.

"Complete source code" means all source code necessary to build, modify, 
and run the software, including build scripts, configuration files, and 
documentation necessary for compilation.

"Publicly accessible and viewable" means that any user of the software 
(whether through distribution or network access) must be able to view and 
obtain the source code without additional fees, registration requirements, 
or unnecessary barriers.

"Perpetual" means that once code is licensed under the OSPL, the source 
visibility requirement continues through all subsequent versions, derivatives, 
and modifications, even if additional or different licenses are applied. This 
creates a permanent obligation that travels with the code.
